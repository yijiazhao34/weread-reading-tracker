# 微信读书阅读追踪

适用于桌面版 Obsidian 1.11.4 或更新版本。安装包已包含插件文件。

## 安装和配置

1. 解压 ZIP，把整个 `weread-reading-tracker` 文件夹放到笔记库的 `.obsidian/plugins/` 下。如果 `plugins` 不存在，创建它。Windows 资源管理器可直接在地址栏输入笔记库路径和 `\.obsidian\plugins`。macOS 可按 `⌘+Shift+.` 显示隐藏文件夹。
2. 重新打开 Obsidian。在 **设置 → 第三方插件** 中开启第三方插件，然后启用 **微信读书阅读追踪**。
3. 打开[微信读书官方页面](https://weread.qq.com/r/weread-skills)，按页面提示登录并复制以 `wrk-` 开头的 API Key。
4. 打开 **设置 → 微信读书阅读追踪**，在 **微信读书 API Key** 中新建机密。名称可填 `weread`，值粘贴官方生成的密钥，再选择这个机密。

## 从 1.0.0 升级

把压缩包中的同名插件文件夹覆盖到 `.obsidian/plugins/`，随后重启 Obsidian。已有笔记可以直接使用新版的章节联动。打开旧笔记后点击 **更新书籍信息**，或在导入窗口重新选中该书，即可补全出版资料。

## 使用

- **导入一本书**。通过左侧书本图标，或在命令面板执行 **导入微信读书目录**。书架按最近阅读时间排序，未有阅读时间的书排在后面。也可以用 **搜书城** 查找。导入的笔记位于 `阅读追踪/`，再次选择同一本书会打开原笔记。若打开后看到 Markdown 源码，可从笔记菜单切换到 **阅读视图**。
- **查看出版资料**。笔记顶部显示微信读书提供的出版社、出版时间、译者、ISBN、分类和字数。可点击 **更新书籍信息** 刷新。
- **勾选章节、小节或小结**。勾选父章节会同时勾选它的所有下属小节，例如勾选 `1` 后，`1.1`、`1.2` 和更深层的小节会一并完成。已有完成时间会保留，新完成的条目记录此次勾选时间。取消勾选只清除当前条目的完成时间。目录未包含的条目可通过 **添加小节或小结** 补上。
- **记录每次阅读**。阅读前点 **开始阅读**，结束时点 **结束阅读**。跨午夜的计时会拆到对应日期，同一天的记录自动合计。忘记计时可用 **补记时长** 填写日期和分钟数。计时按实际经过的时间计算，中途关闭 Obsidian 后仍可回来结束或取消。
- **查看全书统计**。笔记显示累计计时、阅读日期范围和每日时长。全部目录项勾完后会显示完成时间。**刷新微信读书统计** 会读取单本书的累计时长、最近阅读时间和可用的读完日期。微信读书统计单独显示。每日记录来自本地计时和补记。

勾选记录和计时数据都保存在对应书籍的 Markdown 笔记中。自己的摘录和想法可写在笔记下方的 **读书笔记** 区域。API Key 由 Obsidian 的机密存储管理。
